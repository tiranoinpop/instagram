HTML 복습 노트

HTML은 정보와 그 정보의 구조를 표현하는 언어다.
모양(디자인)은 CSS, 동작은 JavaScript가 담당한다.

1. 태그의 기본 문법

<태그명 속성="값">내용</태그명>   <!-- 여는 태그 + 닫는 태그 -->
<태그명 속성="값"/>                 <!-- 내용이 없는 태그 (img, br, input ...) -->
<!-- 주석 : 화면에 안 보임, VS Code 단축키 Ctrl + / -->

2. 문서 기본 구조

<!DOCTYPE html>            <!-- 이 문서는 HTML5 라고 선언 (맨 첫 줄) -->
<html lang="ko">           <!-- 문서 전체를 감싸는 태그 -->
    <head>                 <!-- 화면에 안 보이는 문서 정보 -->
        <meta charset="UTF-8">
        <title>탭 제목</title>
        <link href="./css/style.css" rel="stylesheet">   <!-- 외부 CSS 연결 -->
        <style> /* 문서 안에 CSS 작성 */ </style>
    </head>
    <body>                 <!-- 화면에 보이는 내용 -->
    </body>
</html>
태그역할
<!DOCTYPE html>HTML5 문서 선언
<html>문서 전체(루트). lang="ko"로 언어 지정
<head>문서 정보 영역 (화면에 안 보임)
<meta>인코딩 등 부가 정보
<title>브라우저 탭 제목
<link>외부 파일 연결. href=경로, rel=관계(relation)
<style>문서 안에 CSS 작성
<body>화면에 보이는 내용 영역

html / head / body 를 생략해도 화면이 나오는 이유 : 브라우저가 자동으로 채워 넣어주기 때문 (7_4_2.html).
그래도 항상 직접 작성하는 습관을 들이자.

4. 링크와 이미지

<a href="https://github.com/tiranoinpop/instagram">내 깃허브</a>
<img src="./image/profile2.jpg" alt="프로필 사진" width="80"/>
내 깃허브
태그 / 속성역할
<a href="">링크. href에 이동할 주소
<img src="">이미지. 인터넷 주소(URL)나 내 폴더 경로 모두 가능
alt이미지 설명 (이미지가 안 뜰 때, 화면낭독기용) → 필수
width / height크기. 속성에는 숫자만 (height="100"), 단위는 CSS에서

경로 : ./ = 현재 폴더, ../ = 상위 폴더. ./image/profile2.jpg 는 "현재 폴더 안 image 폴더의 profile2.jpg"

5. 영역 나누기 : div, id, class

<div id="profile">                     <!-- id : 페이지에 단 하나 -->
    <img class="circle_pic" src="..."/>  <!-- class : 여러 요소에 반복 사용 -->
</div>
태그 / 속성역할CSS에서 선택
<div>의미 없는 영역 상자 (레이아웃용)div
id고유한 이름 (중복 X)#profile
class그룹 이름 (중복 O, 여러 개 가능).circle_pic

6. 입력 태그 : input, button

<input type="종류"/> 하나로 type만 바꿔서 여러 입력창을 만든다. 입력받은 데이터는 서버로 전달된다.

6-1. 글자 / 숫자 / 파일 (5_1_2.html)

type코드결과
text<input type="text" value="텍스트"/>
search<input type="search" placeholder="검색"/>
number<input type="number" value="123"/>
password<input type="password"/>
tel<input type="tel"/>
color<input type="color" value="#ff0000"/>
file<input type="file" accept="image/*"/>
button<input type="button" value="버튼1"/>
submit<input type="submit" value="버튼2"/>
(button 태그)<button>좋은버튼</button>

value = 미리 들어있는 실제 값, placeholder = 비어있을 때 보이는 안내 글자.
accept 여러 개는 쉼표로 구분 : accept=".jpg,.png,.pdf"
<button>은 안에 글자, 이미지 등을 넣을 수 있어서 input type="button"보다 자유롭다.
