CSS 공부 노트

HTML이 정보와 구조라면, CSS는 그것의 모양(디자인)을 정하는 언어다.
이 페이지의 "실행 결과"는 예제 코드를 그대로 적용해서 보여준다.

1. CSS 기본 문법

선택자 {
    속성: 값;
    속성: 값;
}

h2 {
    color: black;       /* 주석은 이렇게 */
}
용어의미
선택자 (selector)"어떤 요소에" 적용할지 (h2, .highlight, #profile ...)
속성 (property)"무엇을" 바꿀지 (color, font-size ...)
값 (value)"어떻게" 바꿀지 (black, 30px ...). 속성 뒤에 :, 값 끝에 ;

2. HTML에 CSS 연결하는 3가지 방법 (5_1_1, 7_4_2)

<!-- 1. 외부 파일 : head 안에서 link 태그 (rel = relation, 관계가 뭔지 표시) -->
<link href="./css/style.css" rel="stylesheet">

<!-- 2. style 태그 : 문서 안에 직접 (head 안에 작성) -->
<style>
    p { color: blue; }
</style>

<!-- 3. 인라인 : 태그에 style 속성 -->
<p style="color:red;">어떤결과가 나올까요?</p>

실무에서는 1번(외부 파일)을 가장 많이 쓴다. 여러 페이지가 같은 스타일을 공유하고, HTML이 깔끔해진다.

3. 선택자 (css/style.css)

h2 { color: black; }              /* 1. 태그명 */
.thumbnail { width: 100%; }       /* 2. . + class명 */
#profile { display: grid; }       /* 3. # + id명 */

p img { }                         /* 자손 선택자 : p 안의 모든 img (자식, 손자 모두) */
p>img { }                         /* 자식 선택자 : p 바로 아래 img 만 (손자 X) */
#top img { height: 100%; }        /* 복합 : id 안의 img */
선택자HTML에서 대응되는 것특징
h2<h2>그 태그 전부
.highlightclass="highlight"여러 요소에 반복 사용, 가장 추천
#profileid="profile"페이지에 하나뿐인 요소
p imgp 안쪽 모든 img계층 구조 이용 (추천은 아님, 클래스를 적극 활용)
p>imgp 바로 아래 img자식에게만 적용

4. 적용 순서와 우선순위 (7_3_1, 7_4_2)

4-1. 같은 요소에 여러 스타일이 겹치면 (7_3_1.html)

p {
    border: solid;
    border-color: blue;
}
#myid {
    color: red;
}
.myClass {
    color: green;
    border-color: violet;
}

<p class="myClass" id="myid">어떤 결과가 나올까요?</p>

어떤 결과가 나올까요?

글자색 = 빨강 (id가 class보다 강함), 테두리색 = 보라 (class가 태그보다 강함).
우선순위 : 인라인 style > #id > .class > 태그

4-2. 우선순위가 같으면 나중에 쓴 것이 이긴다 (7_4_2.html)

<link href="./css/7_4_2.css" rel="stylesheet">   <!-- p { color: green; } -->
<style>
    p { color: blue; }                              <!-- 나중에 선언 -->
</style>
<p style="color:red;">어떤결과가 나올까요?</p>    <!-- 인라인 : 최강 -->
<p>이번엔?</p>

어떤결과가 나올까요?

이번엔?

첫 번째 p = 빨강 (인라인), 두 번째 p = 파랑 (link의 초록보다 style이 나중에 선언됨).

6. 박스 모델 : margin, border, padding (8_1_11.html)

[ margin (바깥 여백) [ border (테두리) [ padding (안쪽 여백) [ 내용 ] ] ] ]

9. Grid : 격자 배치 (8_2_1.html)

.myGrid {
    display: grid;
    grid-template-rows: 1fr 3fr;       /* 행 : 높이 비율 1 : 3 */
    grid-template-columns: 1fr 2fr;    /* 열 : 너비 비율 1 : 2 */
}
/* fr 은 fraction(분수, 비율)의 약자 */

12-5. 반응형 : media query

@media (max-width: 600px) {
    .thumbnail_grid { grid-template-columns: 1fr 1fr; }   /* 좁은 화면에서는 2열 */
}

화면 너비에 따라 다른 스타일을 적용한다. 브라우저 창 너비를 줄여보면 이 노트 페이지도 max-width로 폭이 조절되는 걸 볼 수 있다.
