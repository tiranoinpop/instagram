CSS 공부 노트

HTML이 정보와 구조라면, CSS는 그것의 모양(디자인)을 정하는 언어다.
이 페이지의 "실행 결과"는 예제 코드를 그대로 적용해서 보여준다.

1. CSS 기본 문법

선택자 {
    속성: 값;
    속성: 값;
}

h2 {
    color: black;       /* 주석은 이렇게 */
}
용어의미
선택자 (selector)"어떤 요소에" 적용할지 (h2, .highlight, #profile ...)
속성 (property)"무엇을" 바꿀지 (color, font-size ...)
값 (value)"어떻게" 바꿀지 (black, 30px ...). 속성 뒤에 :, 값 끝에 ;

2. HTML에 CSS 연결하는 3가지 방법 (5_1_1, 7_4_2)

<!-- 1. 외부 파일 : head 안에서 link 태그 (rel = relation, 관계가 뭔지 표시) -->
<link href="./css/style.css" rel="stylesheet">

<!-- 2. style 태그 : 문서 안에 직접 (head 안에 작성) -->
<style>
    p { color: blue; }
</style>

<!-- 3. 인라인 : 태그에 style 속성 -->
<p style="color:red;">어떤결과가 나올까요?</p>

실무에서는 1번(외부 파일)을 가장 많이 쓴다. 여러 페이지가 같은 스타일을 공유하고, HTML이 깔끔해진다.

3. 선택자 (css/style.css)

h2 { color: black; }              /* 1. 태그명 */
.thumbnail { width: 100%; }       /* 2. . + class명 */
#profile { display: grid; }       /* 3. # + id명 */

p img { }                         /* 자손 선택자 : p 안의 모든 img (자식, 손자 모두) */
p>img { }                         /* 자식 선택자 : p 바로 아래 img 만 (손자 X) */
#top img { height: 100%; }        /* 복합 : id 안의 img */
선택자HTML에서 대응되는 것특징
h2<h2>그 태그 전부
.highlightclass="highlight"여러 요소에 반복 사용, 가장 추천
#profileid="profile"페이지에 하나뿐인 요소
p imgp 안쪽 모든 img계층 구조 이용 (추천은 아님, 클래스를 적극 활용)
p>imgp 바로 아래 img자식에게만 적용

4. 캐스케이딩(Cascading)과 선택자 우선순위 (7_3_1)

Cascading = 폭포(cascade)처럼 스타일이 위에서 아래로 겹쳐서 흘러내리며 적용된다는 뜻이다. (CSS = Cascading Style Sheets)
같은 요소에 여러 규칙이 동시에 걸리면, 그중 누가 이길지 정하는 규칙이 바로 우선순위다.

🏆 선택자 우선순위 (강한 것 → 약한 것)

#id아이디 선택자
>
.class클래스 선택자
>
태그태그 선택자

더 구체적으로 콕 집은 선택자가 이긴다.
태그(p)는 "모든 p", 클래스(.myClass)는 "이 그룹", 아이디(#myid)는 "딱 이 하나"를 가리키므로 가장 구체적인 #id가 가장 세다.

4-1. 직접 확인해보기 (7_3_1.html)

p {                      /* 태그 선택자 */
    border: solid;
    border-color: blue;     /* 테두리 파랑 */
}
#myid {                  /* 아이디 선택자 */
    color: red;             /* 글자 빨강 */
}
.myClass {               /* 클래스 선택자 */
    color: green;           /* 글자 초록 */
    border-color: violet;   /* 테두리 보라 */
}

<p class="myClass" id="myid">어떤 결과가 나올까요?</p>

어떤 결과가 나올까요?

속성겹친 규칙승자이유
글자색 (color)#myid 빨강 vs .myClass 초록빨강#id > .class
테두리색 (border-color)p 파랑 vs .myClass 보라보라.class > 태그

※ 이 페이지의 실행 결과는 다른 데모와 섞이지 않도록 예제를 .demo1 같은 상자 안에 가둬서 적용했다. 위 코드 박스가 원본이다.

5. 스타일링 방식의 우선순위 : style 속성 → <style> → <link> (7_4_2)

4번이 "어떤 선택자가 센가"라면, 이번에는 "스타일을 어디에 썼는가"에 따른 우선순위다. 같은 요소에 같은 속성을 여러 방식으로 지정했을 때 결과를 정한다.

🏆 스타일 작성 위치 우선순위 (강한 것 → 약한 것)

style="" 속성태그 안에 직접 (인라인)
>
<style> 태그문서 안
>
<link> 연결별도 css 파일

대상에 가까울수록 이긴다. 태그에 직접 쓴 것이 가장 가깝고, 멀리 떨어진 외부 파일이 가장 약하다.
그래서 외부 파일에 기본 디자인을 두고, 필요한 부분만 위에서 덮어쓰는 식으로 활용한다.

5-1. 예시 : 같은 글자색을 세 곳에서 지정

<!-- 1) 외부 파일 (link) : 가장 약함 -->
<link href="./css/priority_demo.css" rel="stylesheet">
<!-- priority_demo.css 내용 -->
.a, .b, .c { color: green; }

<!-- 2) style 태그 : link 보다 강함 -->
<style>
    .b, .c { color: blue; }
</style>

<!-- 3) style 속성 : 가장 강함 -->
<p class="a">A : link만 있음</p>
<p class="b">B : link + style 태그</p>
<p class="c" style="color:red;">C : link + style 태그 + style 속성</p>

A : link만 있음 → 초록

B : link + style 태그 → 파랑 (style 태그가 link를 이김)

C : link + style 태그 + style 속성 → 빨강 (style 속성이 모두를 이김)

문장적용된 스타일글자색
Alink 만초록
Blink, style 태그파랑
Clink, style 태그, style 속성빨강

5-2. 연습 파일 (7_4_2.html)

<link href="./css/7_4_2.css" rel="stylesheet">   <!-- p { color: green; } -->
<style>
    p { color: blue; }
</style>
<p style="color:red;">어떤결과가 나올까요?</p>    <!-- 빨강 : style 속성 -->
<p>이번엔?</p>                                  <!-- 파랑 : style 태그가 link를 이김 -->

어떤결과가 나올까요?

이번엔?

5-3. 주의할 점

  • <style>와 <link>는 사실 같은 급이고, 같은 선택자일 때는 나중에 선언한 쪽이 이긴다.
    위 예시는 link를 먼저, style을 나중에 썼기 때문에 style이 이긴 것이다. 순서를 바꾸면 결과도 바뀐다.
  • 4번의 선택자 우선순위가 먼저다. link 안의 #id 규칙은 style 태그 안의 p 규칙보다 이긴다. (선택자가 서로 다를 때는 위치보다 선택자의 세기가 앞선다)
  • style="" 속성은 HTML 안에 스타일이 섞여서 관리가 어렵다. 연습할 때만 쓰고, 평소에는 link 로 외부 css 파일을 쓰는 것이 좋다.

6. 색상을 표현하는 방법

색은 이름, 16진수, rgb, rgba 등 여러 방식으로 쓸 수 있다. 같은 색을 다르게 표현한 것일 뿐이다.

color: red;                       /* 1. 색 이름 */
color: #ff0000;                   /* 2. 16진수 (#RRGGBB), 줄여서 #f00 */
color: rgb(255, 0, 0);            /* 3. rgb(빨강, 초록, 파랑) 각각 0 ~ 255 */
color: rgba(255, 0, 0, 0.5);      /* 4. rgba(R, G, B, 투명도) 투명도 0 ~ 1 */
방식코드결과
색 이름red
16진수#ff0000
rgbrgb(255, 0, 0)
rgb (다른 색)rgb(0, 128, 255)
rgba (불투명 1)rgba(255, 0, 0, 1)
rgba (반투명 0.5)rgba(255, 0, 0, 0.5)
rgba (거의 투명 0.1)rgba(255, 0, 0, 0.1)
값의미
R, G, B빛의 3원색 (Red, Green, Blue). 각각 0(없음) ~ 255(최대). rgb(0, 0, 0) = 검정, rgb(255, 255, 255) = 흰색
A (alpha)투명도. 0 = 완전 투명, 1 = 불투명. 줄무늬 배경 위에서 비치는 정도로 확인할 수 있다.

rgba는 그 색만 투명하게 만든다. opacity: 0.5는 글자, 테두리, 자식 요소까지 요소 전체를 투명하게 만드는 점이 다르다.

8. 공간(크기)을 표현하는 방법 : px, %, auto, vw / vh

단위의미기준
px화면의 점(픽셀) 크기. 고정값절대 크기
%부모 요소의 몇 퍼센트부모 크기
auto브라우저가 알아서 계산내용 / 남은 공간
vw화면(뷰포트) 너비의 1%브라우저 창 너비
vh화면(뷰포트) 높이의 1%브라우저 창 높이

8-1. % : 부모 기준

.parent { width: 300px; }
.half { width: 50%; }      /* 부모의 절반 = 150px */
.full { width: 100%; }     /* 부모 전체 = 300px */
50%
100%

인스타 클론의 .thumbnail { width: 100% }, 원형 이미지의 height: 100%가 이 방식이다. 부모 크기가 바뀌면 같이 변한다.

8-2. auto : 자동 계산

.centered {
    width: 120px;
    margin-left: auto;      /* 남은 공간을 좌우로 똑같이 나눔 → 가운데 정렬 */
    margin-right: auto;
}
img { height: auto; }       /* 가로 크기에 맞춰 비율 유지 */
auto 로 가운데

margin: auto 가운데 정렬은 width가 정해진 block 요소에서 동작한다. (이 노트 페이지의 body도 max-width + margin auto로 가운데 정렬했다.)

8-3. vw / vh : 화면 크기 기준

.vw10 { width: 10vw; }     /* 화면 너비의 10% */
.vw30 { width: 30vw; }     /* 화면 너비의 30% */
.vw50 { width: 50vw; }     /* 화면 너비의 50% */
.vh   { height: 10vh; }    /* 화면 높이의 10% */
10vw
30vw
50vw

브라우저 창 크기를 줄였다 늘려보면 막대 길이가 같이 변한다. (%는 부모 기준, vw/vh는 화면 전체 기준이 차이점)
화면을 꽉 채우는 영역은 width: 100vw; height: 100vh; 로 만든다.

15. 미디어 쿼리와 반응형 웹페이지

반응형 웹 = 하나의 HTML이 PC, 태블릿, 모바일 등 화면 크기에 맞춰 레이아웃이 알아서 바뀌는 웹페이지.
그 핵심 도구가 미디어 쿼리 (@media)다. "화면이 이럴 때만 이 스타일을 적용해라"라는 조건문 같은 것이다.

15-1. 기본 문법

@media (조건) {
    선택자 {
        속성: 값;
    }
}

/* 예 : 화면 너비가 600px 이하일 때만 적용 */
@media (max-width: 600px) {
    .thumbnail_grid { grid-template-columns: 1fr 1fr; }
}

조건이 참일 때만 중괄호 안의 규칙이 적용되고, 거짓이면 통째로 무시된다. 안쪽에는 평소처럼 선택자와 속성을 쓰면 된다.

조건의미예시
max-width화면 너비가 이 값 이하일 때 (좁은 화면)(max-width: 600px)
min-width화면 너비가 이 값 이상일 때 (넓은 화면)(min-width: 1024px)
범위and 로 조건을 이어서 사이 구간 지정(min-width: 601px) and (max-width: 1023px)
orientation화면 방향(orientation: portrait) 세로 / landscape 가로
prefers-color-scheme사용자의 다크 모드 설정(prefers-color-scheme: dark)
print인쇄할 때@media print { ... }

15-3. 반응형을 만들 때 알아둘 것

  • viewport 설정이 필수다. head에 아래 줄이 없으면 모바일 브라우저가 "PC 화면"처럼 축소해서 보여주고, 미디어 쿼리가 의도대로 동작하지 않는다. 
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • 분기점(breakpoint) : 레이아웃이 바뀌는 너비. 정해진 값은 없고 관례적으로 아래 정도를 쓴다.
    화면너비 (대략)
    모바일~ 600px
    태블릿601px ~ 1023px
    PC1024px ~
  • 작성 방식 두 가지 : max-width로 "PC 기본 → 작은 화면에서 덮어쓰기", 또는 min-width로 "모바일 기본 → 큰 화면에서 덮어쓰기"(모바일 우선, 요즘 많이 쓰는 방식).
  • 쓰는 위치(순서)에 주의. @media 안의 규칙도 4~5번의 우선순위 규칙을 그대로 따라서, 같은 선택자라면 나중에 쓴 것이 이긴다. 그래서 @media 블록은 기본 스타일 뒤쪽에 둔다. (@media 자체가 선택자의 세기를 올려주지는 않는다.)
  • 앞에서 배운 %, vw, grid의 fr, auto가 이미 반은 반응형이다. 미디어 쿼리는 그것으로 해결 안 되는 구조 변경(4열 → 2열, 메뉴 숨김 등)에 쓴다.

15-4. <link> 태그에도 미디어 쿼리 : media 속성

CSS 파일 안에 @media를 쓰는 대신, <link> 태그의 media 속성에 조건을 주면 화면에 따라 다른 CSS 파일을 적용할 수 있다.

<!-- 화면 너비 700px 이상일 때만 적용 -->
<link href="./css/media_demo_wide.css" rel="stylesheet" media="(min-width: 700px)">

<!-- 화면 너비 699px 이하일 때만 적용 -->
<link href="./css/media_demo_narrow.css" rel="stylesheet" media="(max-width: 699px)">

<!-- 인쇄할 때만 적용 -->
<link href="./css/print.css" rel="stylesheet" media="print">

창 너비를 700px 근처에서 줄였다 늘려보면 적용되는 CSS 파일이 통째로 바뀌는 것을 볼 수 있다.
(위 결과의 초록 / 주황 상자는 각각 별도 파일 media_demo_wide.css, media_demo_narrow.css가 만든 것이다.)

방식코드장단점
CSS 안에 @media@media (max-width: 600px) { ... }한 파일에서 기본 스타일과 변경점을 같이 볼 수 있다. 일반적으로 많이 쓴다.
link 의 media 속성<link media="(max-width: 600px)" ...>화면별 / 인쇄용 파일을 완전히 분리할 수 있다. 파일 수가 늘어난다.

20. box-sizing : 크기 계산 방식

기본값(content-box)은 width가 내용 영역만의 폭이라서, padding과 border를 더하면 실제 폭이 커진다. border-box는 padding과 border를 width 안에 포함해서 계산한다.

.a { box-sizing: content-box; width: 200px; padding: 20px; border: 5px solid; }  /* 실제 250px */
.b { box-sizing: border-box;  width: 200px; padding: 20px; border: 5px solid; }  /* 실제 200px */

/* 거의 모든 CSS 파일 맨 위에 있는 관용구 */
* { box-sizing: border-box; }
content-box (200 + 40 + 10 = 250px)
border-box (200px 그대로)

AI가 쓴 CSS 맨 위에 * { box-sizing: border-box; }가 있다면 "크기 계산을 직관적으로 만들려는 것"이다.

25. 상속(inherit)과 !important

25-1. 상속

부모에게 준 일부 스타일은 자식에게 자동으로 전해진다. 글자 관련(color, font-*, text-align 등)은 상속되고, 모양 관련(border, margin, padding, background)은 상속되지 않는다.

.parent { color: red; border: 2px solid; }
<div class="parent">부모 글자 <span>자식 글자</span></div>
부모 글자 자식 글자 (색은 상속 / 테두리는 상속 안 됨)

그래서 body { font-family: ...; } 한 줄로 페이지 전체 글꼴을 정할 수 있다. 상속 안 되는 값도 inherit를 쓰면 부모 값을 가져온다. (border: inherit;)

25-2. !important

p { color: red !important; }      /* 4~5번의 모든 우선순위 규칙을 무시하고 최우선 */

가급적 쓰지 않는다. 한 번 쓰면 다른 스타일로 덮어쓰기가 어려워진다. AI가 쓴 코드에 !important가 보이면 "우선순위 충돌을 억지로 해결한 곳"이라고 보면 된다.

26. 선택자 심화 : 자주 보이는 형태

h1, h2, h3 { margin: 0; }          /* 쉼표 : 여러 선택자에 같은 스타일 */
.card.active { color: red; }       /* 붙여 쓰기 : card 이면서 active 인 요소 */
a[target="_blank"] { }             /* 속성 선택자 : 속성값으로 찾기 */
li:first-child { }                 /* 첫 번째 자식 */
li:nth-child(even) { }             /* 짝수 번째 (odd = 홀수, 3 = 3번째) */
p::before { content: "★ "; }      /* 요소 앞에 내용 추가 (::after = 뒤) */
h2 + p { }                         /* 바로 다음 형제 */
  • 1번 줄
  • 2번 줄 (짝수)
  • 3번 줄
  • 4번 줄 (짝수)

위 목록은 li:nth-child(even) { background-color: ... } 로 짝수 줄만 색을 입혔다. 표나 목록의 줄무늬에 자주 쓰인다.

27. 개발자 도구(F12) : CSS를 눈으로 확인하는 법

AI가 쓴 CSS를 이해하고 고치는 데 가장 도움이 되는 도구다. 크롬 / 엣지에서 F12를 누른다.

기능방법용도
요소 선택Ctrl + Shift + C 후 화면 클릭그 요소에 적용된 CSS 확인
Styles 패널오른쪽 패널의 Styles 탭적용된 규칙 / 취소선(덮어씌워져 무시된 규칙) 확인 → 4~5번 우선순위를 눈으로 확인
값 직접 수정Styles 패널에서 값을 클릭해서 수정저장 전에 결과를 바로 시험 (새로고침하면 사라짐)
박스 모델 그림Computed 탭margin, border, padding, 실제 크기 확인
모바일 화면Ctrl + Shift + M폰 / 태블릿 크기로 보기 (15번 미디어 쿼리 확인)

"왜 이 색이 안 먹지?", "왜 여기에 간격이 생기지?" 할 때 추측하지 말고 F12로 확인하는 것이 가장 빠르다.
